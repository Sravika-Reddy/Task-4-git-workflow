\# Task 4: Version-Controlled DevOps Project



\## Objective

Manage a DevOps project using Git and GitHub best practices.



\## Tools Used

\- Git

\- GitHub

\- Windows CMD



\## Project Tasks

\- Initialize a local Git repository.

\- Create main, dev, and feature branches.

\- Track changes using commits.

\- Merge changes using GitHub pull requests.

\- Use a .gitignore file.

\- Create Git tags for releases.

\- Document the workflow using Markdown.



\## Branching Strategy

\- main: Stable project version.

\- dev: Integration branch.

\- feature/readme: Feature-specific changes.



\## Outcome

Learn Git version control, branching, commits, pull requests, and release tagging.
