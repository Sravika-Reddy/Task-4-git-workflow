\# Git Workflow Documentation



\## Step 1: Repository Initialization

Initialize a local repository using git init.



\## Step 2: Branching

Use main for stable changes, dev for integration,

and feature branches for individual tasks.



\## Step 3: Commits

Save logical changes with meaningful commit messages.



\## Step 4: Pull Requests

Review and merge feature changes through GitHub pull requests.



\## Step 5: Release Tags

Use Git tags to identify project versions.
